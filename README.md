KIDNEY HEALTH CLASSIFICATION 🩺
----------------------------

📌 Project Overview

The Kidney Health Classification project is developed using a synthetic yet medically realistic dataset containing kidney-related health indicators. The main objective of this project is to analyze patient health data and classify the presence of Chronic Kidney Disease (CKD) using Machine Learning techniques.


This project helps in:


Early detection of kidney disease
Understanding important health indicators
Identifying disease patterns
Supporting clinical decision-making through predictive analytics

📂 Dataset Features


The dataset contains the following health indicators:

Creatinine
BUN (Blood Urea Nitrogen)
GFR (Glomerular Filtration Rate)
Urine Output
Diabetes
Hypertension
Age
Protein in Urine
Water Intake
Medication
CKD Status
